德州AI源码

C++ CFR 引擎与 Python 训练评估项目，面向 HUNL 非完美信息博弈、自我博弈、反事实价值和策略重解研究。

可核对的技术模块

  • csrc/：CFR、博弈树和底层计算
  • cfv/：反事实价值计算
  • rela/：强化学习智能体组件
  • game/：动作空间、状态与规则逻辑
  • benchmark/、tests/：评估和测试

项目界面

研究边界

基准胜率需要结合提交版本、随机种子、对手实现、盲注、筹码深度、手数和置信区间复现。本项目用于研究与教育，不应用于实时作弊、未授权自动代打或违反平台规则的活动。
