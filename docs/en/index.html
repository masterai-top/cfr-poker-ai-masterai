CFR Poker AI Source Code

MasterAI is a research codebase for heads-up no-limit Texas Hold'em (HUNL), focused on counterfactual regret minimization, self-play, counterfactual value estimation and strategy evaluation.

Scope and responsible evaluation

This repository targets game theory, imperfect-information games and offline strategy experiments. Verify dependencies, configurations, seeds and benchmark protocols before drawing conclusions. Do not use it for real-time assistance, automated play on third-party services or rule circumvention.
